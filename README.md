# Bad Apple Pixel Replacer

[한국어](README.md) | [English](README.en.md) | [日本語](README.ja.md)

흑백 대비가 뚜렷한 영상(Bad Apple 등)의 검정/흰색 픽셀을 사용자가 지정한 두 이미지로 치환하여
모자이크 형태의 영상으로 렌더링하는 GUI 프로그램입니다.

## 주요 기능

- 원본 영상, 검정 대응 이미지, 흰색 대응 이미지를 각각 업로드
- 배경(선택사항): 정지 이미지뿐 아니라 GIF/영상도 지정 가능하며, 원본 영상이 끝날 때까지 자동 반복 재생
- 투명 배경(PNG 등)을 가진 이미지를 넣으면 지정한 배경이 투명한 부분 뒤로 비쳐 보임
- FPS 조절
- 해상도 조절 (가로 방향 셀 개수, 세로는 원본 비율에 맞춰 자동 계산)
- 픽셀 대응 이미지 품질 선택 (낮음 32px / 중간 64px, 권장 / 높음 96px)
- 한국어 / English / 日本語 3개 언어 지원 (프로그램 우측 상단에서 전환)
- 렌더링은 별도 스레드에서 진행되어 GUI가 멈추지 않으며, 진행률 표시

## 폴더 구성

```
.
├── initial_setting.bat   # 최초 1회 실행: venv 생성 + 필요 라이브러리 설치
├── run.bat               # 실행할 때마다: venv 활성화 후 GUI 실행
├── main.py               # GUI + 렌더링 로직
├── LICENSE               # MIT 라이선스
├── venv/                 # initial_setting.bat 실행 시 자동 생성 (gitignore 대상)
└── result/               # 렌더링 결과가 저장되는 폴더 (자동 생성, gitignore 대상)
```

## 사용 방법 (Windows)

1. **최초 1회만**: `initial_setting.bat` 더블클릭
   - `venv` 폴더 생성
   - PySide6, opencv-python, pillow, imageio, imageio-ffmpeg, numpy 자동 설치
2. **실행할 때마다**: `run.bat` 더블클릭
   - venv 활성화 후 GUI 창이 뜸
3. GUI에서 아래 항목을 설정합니다.
   - 원본 영상 선택 (mp4, avi, mov, mkv)
   - 검정 픽셀 대응 이미지 선택
   - 흰색 픽셀 대응 이미지 선택
   - (선택) 배경 이미지/영상/GIF 선택 — 투명 배경이 있는 이미지를 쓸 때만 의미가 있음
   - FPS, 해상도, 픽셀 이미지 품질 조절
4. **렌더링** 버튼 클릭 → 진행률 표시 → 완료 팝업에서 **폴더 열기**로 결과 확인
5. 결과 영상은 `result/output.mp4`에 저장됩니다. 다시 렌더링하면 이전 결과는 덮어써집니다.

## 요구 사항

- Python 3.9 이상 (PATH에 등록되어 있어야 함)
- Windows 환경 (배치 파일 기준. macOS/Linux에서는 `main.py`를 venv 안에서 직접 실행하면 동일하게 동작)

## 참고 사항

- 화질을 높이고 싶다면 "픽셀 대응 이미지 품질"을 높음으로, 해상도(가로 셀 개수)를 올리면 되지만
  둘 다 값이 커질수록 최종 영상 해상도와 렌더링 시간, 파일 용량이 함께 증가합니다.
  체감상 품질 단계 하나를 올리면 픽셀 수는 제곱으로 늘어나니, 먼저 중간(64px)으로 테스트해보는 것을 권장합니다.
- 배경으로 영상/GIF를 사용하면 정적 이미지보다 렌더링이 다소 느려질 수 있습니다 (프레임마다 배경을 다시 준비하기 때문).
- 렌더링된 영상에는 오디오가 포함되지 않습니다 (원본 영상의 프레임만 사용).
