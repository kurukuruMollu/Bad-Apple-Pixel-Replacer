# Bad Apple Pixel Replacer

[한국어](README.md) | [English](README.en.md) | [日本語](README.ja.md)

白黒のコントラストがはっきりした動画(Bad Appleなど)の黒/白ピクセルを、
ユーザーが指定した2枚の画像に置き換え、モザイク風の動画としてレンダリングするGUIプログラムです。

## 主な機能

- 元動画、黒ピクセル対応画像、白ピクセル対応画像をそれぞれアップロード
- 背景(任意): 静止画像だけでなくGIF/動画も指定可能で、元動画が終わるまで自動でループ再生
- 透明背景(PNGなど)を持つ画像を使用すると、指定した背景が透明な部分の背後に透けて見える
- FPS調整
- 解像度調整(横方向のセル数、縦は元動画の比率に合わせて自動計算)
- ピクセル対応画像の品質選択(低 32px / 中 64px、推奨 / 高 96px)
- 韓国語 / English / 日本語の3言語対応(アプリ右上から切り替え)
- レンダリングは別スレッドで実行されるためGUIがフリーズせず、進捗バーを表示

## フォルダ構成

```
.
├── initial_setting.bat   # 初回のみ実行: venv作成 + 必要なライブラリのインストール
├── run.bat                # 実行するたびに: venvを有効化してGUIを起動
├── main.py                # GUI + レンダリングロジック
├── LICENSE                # MITライセンス
├── venv/                  # initial_setting.bat実行時に自動生成(gitignore対象)
└── result/                # レンダリング結果が保存されるフォルダ(自動生成、gitignore対象)
```

## 使い方 (Windows)

1. **初回のみ**: `initial_setting.bat` をダブルクリック
   - `venv` フォルダを作成
   - PySide6, opencv-python, pillow, imageio, imageio-ffmpeg, numpy を自動インストール
2. **実行するたびに**: `run.bat` をダブルクリック
   - venvが有効化されGUIウィンドウが起動
3. GUIで以下の項目を設定します。
   - 元動画を選択(mp4, avi, mov, mkv)
   - 黒ピクセル対応画像を選択
   - 白ピクセル対応画像を選択
   - (任意) 背景の画像/動画/GIFを選択 — 黒/白画像が透明背景を持つ場合のみ意味があります
   - FPS、解像度、ピクセル画像品質を調整
4. **レンダリング** ボタンをクリック → 進捗バーを確認 → 完了ダイアログの **フォルダを開く** で結果を確認
5. 結果動画は `result/output.mp4` に保存されます。再度レンダリングすると以前の結果は上書きされます。

## 動作要件

- Python 3.9 以上(PATHに登録されている必要があります)
- Windows環境(バッチファイル基準。macOS/Linuxでは venv内で `main.py` を直接実行すれば同様に動作します)

## 補足事項

- 画質を上げたい場合は「ピクセル対応画像の品質」を高に、解像度(横方向のセル数)を上げれば良いですが、
  どちらも値が大きくなるほど最終的な動画解像度・レンダリング時間・ファイル容量が共に増加します。
  品質を1段階上げるとピクセル数は2乗で増えるため、まずは中(64px)で試してみることをおすすめします。
- 背景に動画/GIFを使用すると、静止画像よりもレンダリングがやや遅くなる場合があります(フレームごとに背景を再準備するため)。
- レンダリングされた動画には音声は含まれません(元動画のフレームのみを使用します)。
